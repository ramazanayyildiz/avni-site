# Avni

Static concept site for Avni, a macOS YouTube Music companion with classic skins.

This repository contains only the public landing page and its original artwork. The desktop application is still in development and is not distributed here.

Serve `index.html` with any static web server. The page uses relative asset paths and requires no build step. GitHub Pages can publish this repository from the root of `main`.

Avni is independent of Google and YouTube. All skin imagery on this page was created for Avni; no historic Winamp skin artwork is included.

The approved Avni identity pairs an amber pixel A/play symbol with an ivory wordmark and graphite app icon. The logo and icon were created for Avni with imagegen; the small favicon is a matching vector adaptation. The desktop application source license selected by the owner is MIT.
